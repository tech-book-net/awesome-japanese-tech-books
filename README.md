## Software Architecture & Design

- **データ指向アプリケーションデザイン** by Martin Kleppmann(オライリー・ジャパン) — 分散システムの信頼性・拡張性・保守性を体系的に扱う。「DDIA」の通称で広く読まれる定番。 [tech-book.net](https://www.tech-book.net/books/9784873118703)
- **モノリスからマイクロサービスへ** by Sam Newman(オライリー・ジャパン) — 既存のモノリシックなシステムを段階的に分解する実践的アプローチ。 [tech-book.net](https://www.tech-book.net/books/9784873119311)
- **現場で役立つシステム設計の原則** by 増田亨(技術評論社) — DDD の考え方を日本語で噛み砕いた定番入門書。 [tech-book.net](https://www.tech-book.net/books/9784774190877)
- **ちょうぜつソフトウェア設計入門** by 田中ひさてる(技術評論社) — PHP を題材にオブジェクト指向設計の本質を解説。言語を超えて学べる。 [tech-book.net](https://www.tech-book.net/books/9784297132347)
- **オブザーバビリティ・エンジニアリング** by Charity Majors ほか(オライリー・ジャパン) — 分散システムの可観測性をどう設計するか。SRE 必読。 [tech-book.net](https://www.tech-book.net/books/9784814400126)

## Programming Languages

- **プロになるJava** by きしだなおき・山本裕介・杉山貴章(技術評論社) — 仕事で必要な Java の知識をゼロから扱う実践的入門。 [tech-book.net](https://www.tech-book.net/books/9784297126858)
- **Java本格入門** by 谷本心・阪本雄一郎ほか(技術評論社) — モダン Java(Stream / Optional / 関数型)を業務観点で解説。 [tech-book.net](https://www.tech-book.net/books/9784774189093)
- **Javaパフォーマンス** by Scott Oaks(オライリー・ジャパン) — JVM チューニングと GC の体系的解説。 [tech-book.net](https://www.tech-book.net/books/9784873117188)
- **プロを目指す人のためのTypeScript入門** by 鈴木僚太(技術評論社) — 「ブルーベリー本」。型システムを安全に使い切る本格派。 [tech-book.net](https://www.tech-book.net/books/9784297127473)
- **1冊ですべて身につくJavaScript入門講座** by Mana(SBクリエイティブ) — フロントエンド入門の定番、初学者向け。 [tech-book.net](https://www.tech-book.net/books/9784815615758)

## Web & Networks

- **Webを支える技術** by 山本陽平(技術評論社) — HTTP・URI・REST の基礎。Web エンジニア必読の古典。 [tech-book.net](https://www.tech-book.net/books/9784774142043)
- **Real World HTTP 第3版** by 渋川よしき(オライリー・ジャパン) — HTTP の進化を実装観点で追える。HTTP/3 にも対応。 [tech-book.net](https://www.tech-book.net/books/9784814400669)
- **ネットワークはなぜつながるのか 第2版** by 戸根勤(日経BP) — Web ブラウザのアドレス入力からサーバ応答までを通しで追う名著。 [tech-book.net](https://www.tech-book.net/books/9784822283117)

## Database

- **初めてのSQL 第3版** by Alan Beaulieu(オライリー・ジャパン) — SQL の基礎から実務的なクエリまでをカバー。 [tech-book.net](https://www.tech-book.net/books/9784873119588)
- **SQLパズル** by ジョー・セルコ(翔泳社) — SQL の発想力を鍛えるパズル集。脱・初心者の決定打。 [tech-book.net](https://www.tech-book.net/books/9784798114132)
- **絵で見てわかるSQL Serverの仕組み** by 平山理(翔泳社) — SQL Server の内部動作を図解で追える。 [tech-book.net](https://www.tech-book.net/books/9784798158723)

## Linux & OS

- **入門 モダンLinux** by Michael Hausenblas(オライリー・ジャパン) — 現代の Linux ディストロ・コンテナを前提にした入門書。 [tech-book.net](https://www.tech-book.net/books/9784814400218)
- **マスタリングLinuxシェルスクリプト 第2版** by Mokhtar Ebrahim ほか(オライリー・ジャパン) — bash / 実用スクリプトを体系的に。 [tech-book.net](https://www.tech-book.net/books/9784814400119)
- **ITエンジニア1年生のための まんがでわかるLinux コマンド&シェルスクリプト基礎編** by Piro / 日経Linux(日経BP) — 入門の入門。 [tech-book.net](https://www.tech-book.net/books/9784296112159)

## AI / Machine Learning

- **生成AI時代の価値のつくりかた** by Rob Thomas ほか(オライリー・ジャパン) — 経営・プロダクト視点での生成 AI 活用論。 [tech-book.net](https://www.tech-book.net/books/9784814401291)

## Generative AI / LLM

- **大規模言語モデル入門** by 山田育矢・鈴木正敏ほか(技術評論社) — transformers を使いながら LLM の仕組みと日本語処理を学ぶ体系的入門。 [tech-book.net](https://www.tech-book.net/books/9784297136338)
- **大規模言語モデル入門2 生成型LLMの実装と評価** by 山田育矢ほか(技術評論社) — 続編。生成型 LLM の学習・評価・RLHF まで実装ベースで扱う。 [tech-book.net](https://www.tech-book.net/books/9784297143930)
- **LLMのプロンプトエンジニアリング** by John Berryman・Albert Ziegler(オライリー・ジャパン) — GitHub Copilot の開発経験に基づくプロンプト設計の原理。 [tech-book.net](https://www.tech-book.net/books/9784814401130)
- **Azure OpenAI ServiceではじめるChatGPT/LLMシステム構築入門** by 永田祥平ほか(技術評論社) — RAG 構成を含む業務システムへの LLM 組み込みの実践書。 [tech-book.net](https://www.tech-book.net/books/9784297139292)
- **AIエージェント開発 / 運用入門** by 御田稔ほか(SBクリエイティブ) — エージェント設計・ツール連携・運用までを扱う生成 AI 深掘りガイド。 [tech-book.net](https://www.tech-book.net/books/9784815636609)

- **東京大学のデータサイエンティスト育成講座** by 塚本邦尊ほか(マイナビ出版) — Python での前処理〜モデリングを演習形式で通す。 [tech-book.net](https://www.tech-book.net/books/9784839965259)
